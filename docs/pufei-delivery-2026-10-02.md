# 扑飞修复与共享工程打包记录（2026-10-02）

当前共享工作区全部生产源码参与 Release 构建，包括其他 AI 已写入工程的改动；没有还原或筛掉其他人的更新。应用版本 1.1.1 / 199，扑飞脚本版本 1.0.3。

## 本次修复

- 长 Base64 阅读参数改为有界扫描，避免整段 HTML 的贪婪正则；空响应先判空，保留读取预算。
- 搜索保留同名条目的公开上游线索，解析完整目录，匹配已确认别名，保留旧版/全彩版区别；失效上游只查找同名条目。
- 读取公开图片数据、还原原图转发链接、使用实际 WebP 路径；详情和页列表采用有期限、容量限制的缓存。
- 对已确认的爱国漫公开镜像使用正确 Referer、原章节 ID 和电脑版/手机版回退，详情展示实际备用阅读线路。
- 仅扑飞的爱国漫域名在配置的 HTTP 代理失败后尝试 HTTPS 直连：最多两次连接、保留超时和取消、保持 TLS 校验。此处不修改系统代理设置、VPN 或小说源逻辑。
- 原生网络桥的 JSON 字符串先解析再消费错误，避免旧 QuickJS 将已捕获的异步网络拒绝仍视为终止错误。
