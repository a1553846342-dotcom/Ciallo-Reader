# 漫画阅读器加载与手势优化

## 加载策略

- 当前可见页走前台加载；它尚未完整就绪时，在线后台预取等待，避免在慢图床上抢带宽。当前页成功或失败后释放预取。
- 分页阅读预先准备后面两跨页和前面一跨页。条漫沿用滚动窗口；旧窗口任务取消，内存驻留仍受预算限制，并遵守仅 Wi-Fi 预加载设置。
- 当前页缓存命中直接显示；未命中时真实字节进度提示下载情况。响应没有 Content-Length 时显示接收字节数，不模拟百分比。
- 慢下载的普通渐进式 JPEG：从同一个 HTTP 响应提取已完成的扫描层，后台解码整页预览，再随更多扫描层更新，最终换成完整页面。不另发缩略图请求，不把残缺数据当作完整页面缓存。
- 预览仅尝试处理前 2 MB，每次采样阈值递增；全局最多一个预览解码任务。快速下载直接走完整解码；普通 JPEG、PNG、WebP 等识别后跳过渐进解码。需要 AES 解密或 JS 图片重排的页跳过网络预览。
- 即使开启画质增强，原图解码后也先显示正确拆页、裁切和旋转的可读预览，再完成增强处理。
- 解码按长边适配，保留小图原始尺寸，避免先放大或过大解码再缩小。连接允许 HTTP/2 协商，共享已有连接，取消额外的首图 HEAD 请求。
- 当前页就绪立即更新卷页纹理，不等待前后页。失败有明确重试入口，等待较久也能手动重新加载；损坏磁盘缓存不永久阻塞重试。
- URL、请求头和 Referer 一起组成缓存身份，避免不同请求条件复用旧内容。请求失败退避短且可取消，最后一次失败后不再额外睡眠。

## 手势策略

- 支持双击缩放时，第一击等待双击判定；第二击取消单击动作，避免先翻页或打开面板再缩放。关闭双击时单击立即执行。
- 新手势中断旧惯性和回弹，并取消未执行的单击。QuickZoom 使用始终为正的连续缩放比例。
- 放大内容和双指手势优先于边缘退出；边缘退出使用最新的回调和缩放状态。
- 卷页拖拽采用系统触摸阈值，减少起手迟滞。新页面状态和绘制位图同步，避免上一页残留、Ready 但尚未有图的一帧空白。

## 验证和限制

回归测试覆盖缓存身份、请求去重、换页无旧图、HTTP 失败、预览几何、前台与预取顺序、双击和边缘退出，并通过本地 HTTP 服务模拟慢响应：关闭增强，先发送图片前 32 KB、暂停后续字节，验证预览已出现且完整页缓存仍为空，恢复响应后验证完整页替换和只请求一次。

渐进预览取决于图片编码。普通 JPEG、PNG、WebP、加密及重排页仍需收齐所需数据；服务器尚未响应或尚未发出足够的扫描数据时无法凭空出图。没有测量真实图源在不同网络下的冷加载速度，也未连接 Android 真机验证 GL 卷页的最终合成画面。

源的目录、会话、代理路径和整章下载另有优化；实际结果详见 [漫画源实测记录](comic-source-verification-2026-09-30.md)。这些策略不需要开启画质增强。最新安卓原生桥与阅读器回归 12 项通过，其中真实慢 HTTP 渐进图测试已证明增强关闭时仍能先显示预览、再替换完整图片，且只请求一次。累计 19 个源、1,800 页完成整章下载和离线验证；MYComic 清除会话后直接通过，NHentai 匿名直接通过，均未预先进行手动站点验证。
