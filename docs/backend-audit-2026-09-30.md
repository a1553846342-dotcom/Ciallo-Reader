## 本轮实际结果

- 导入/删书/神回封面/备份恢复使用明确事务与锁顺序；中断导入不留下部分章节书。移除破坏性数据库升级，补早期版本保留迁移并导出 Room schema。
- 小说下载具备可信续传、前台通知、源限定身份、取消关闭连接、可离线重试入库；请求头加密持久化并用于恢复，跨域/降级跳转不带手工认证头。漫画改为持久描述与 WorkManager，重启补提交、复用已下载页、正确保护暂停文件。
- 设置页提供完整 ZIP 备份入口，流式保存用户数据表、私有原书、图片、标注、收藏、阅读记录、神回和设置；验证后事务恢复并重定位路径。凭据/PIN/模型/下载队列/含认证配置的书源 JSON 不导出。
- 三个 ONNX 验证固定 SHA-256，OCR 使用固定 revision；校验缓存与异步首次验证避免反复读取大模型。推理 admission/关闭同锁，图像、解压和 JS 图片桥有内存预算与回收。
- QuickJS AST 为循环/函数/catch/动态 Function 注入取消和 45 秒检查，eval 明确拒绝；输入/堆/栈/规则/复杂正则有预算。HTTP 共享 pool/dispatcher，取消覆盖 body 读取；Cronet 响应有上限、等待观察取消。
- 阅读统计跨本地午夜切段、事务累计、保留旧时长；恢复 epoch 拒绝排队的旧进度/统计。漫画章节目录按稳定身份与唯一卷标题迁移；TTS 有长段拆分、回调推进、音频焦点、后台通知及代次保护。
- PIN PBKDF2 升级与失败冷却，计算离开 UI 线程；AI Key 加密迁移，隐私/无痕阻止在线翻译；译文缓存加入像素哈希和模型配置；敏感日志与系统自动备份关闭。

## 使用与实际限制

在“设置 → 数据备份”导出ZIP。恢复会替换当前用户数据、暂停下载并重新打开应用。登录凭据、PIN、模型、下载队列和含认证信息的书源配置不包含在便携文件中；外部 content URI 未复制的历史原文件不能凭备份恢复。

这些修改已处理核验出的主要后端故障与资源风险，不能把“56项均有结论”写成“56个大类在所有环境完全消失”。真机后台行为、native库、原始历史数据库/格式样本、真实节点会话仍是明确的验证边界。
