# 小说搜索卡片与漫画源修复（2026-10-01）

Z-Library 在聚合小说搜索和单源搜索中统一使用小说卡片。点击只打开详情，读取简介；点击详情中的下载按钮才检查登录并进入原有下载流程。真实 Z-Library 仍使用原有封面加载器、格式选择、登录与下载实现。

所有小说卡片移除添加／取消喜欢的爱心。漫画收藏功能保留；已有收藏数据不删除。整本小说导入和检查更新的源白名单仍仅包含 auto_novel、wenku8_library、ixdzs8，Z-Library 未进入更新导入器。

Z-Library 的详情补充真实简介、出版社、年份、页数、ISBN 等站点提供的字段，缺失字段不伪造。与添加中文网文源前记录的 30 个 Z-Library 文件散列相比，28 个不变，2 个仅增加详情展示数据：ZLibrarySource.kt、ZLibraryEapiClient.kt。

扑飞的 GET 请求在 Chromium 网络栈返回断连错误后，增加完整请求的 OkHttp 重试，兼容 VPN 通过系统隧道工作、没有系统 HTTP 代理的情况。正常请求继续走原通道，缓存和阅读加载策略保留。

哔哩请求使用一致的移动端请求头、同源 Referer 和详情 Cookie，并启用 HTTP/2；GET 断连或 403 时允许另一网络通道重试。网络桥保留实际响应地址。搜索唯一命中并跳转详情时，从实际详情地址取得漫画编号，避免错误选择搜索弹窗、推荐区中更早出现的另一漫画编号；非搜索／详情响应不再当作搜索结果。
