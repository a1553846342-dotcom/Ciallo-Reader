# 聚合漫画搜索加速（2026-10-02）

本轮仅修改书库搜索调度与结果展示。没有修改 `source/`、JS 源脚本、源配置、网络实现、解析器、章节或图片加载逻辑。小说聚合继续使用原有调度。

## 改动

- 新增 `library/ComicAggregateSearch.kt`：漫画搜索并发上限从 4 提升为 8，信号量跨查询复用。所有源的原词请求先排队，本地多语言标题查询同时进行；别名不会抢占尚未开始的原词请求。同一源内仍串行搜索，保留全部语言变体和全部不同资源。
- `LibraryViewModel.kt` 仅增加漫画搜索调度器及漫画分支接线。取消旧搜索、代次校验继续阻止过期查询回写。
- `LibraryScreen.kt` 原来在 `loading=true` 时只显示骨架，即使该源已经返回书卡。现在立即显示已返回结果，组头继续标示后台补充进度。首次有结果的源排到前面，后续有结果的源按首次命中顺序追加；源内用资源 ID 去重，不跨源合并。
- 速跳索引按实际显示的书卡、折叠按钮计算。只在等待首个结果且停在顶部时跟随到结果顶部；从详情返回保留滚动位置。
