# 绅士漫画、漫小肆、MangaDex 修复（2026-10-02）

## 问题与修复

- 绅士漫画：原生 Android 运行时复现 `cannot read property 'text' of undefined at load (source.js:491)`。手机 UA 收到移动版搜索页，其中没有旧版 `p.result > b` 和桌面漫画列表。搜索同时支持移动版、桌面版，分页从总数或分页链接提取；空结果和异常网页分开处理。补丁版本升至 39，原始脚本和旧版已打补丁的缓存均可在本地修复，重复应用保持一致。
- 漫小肆：保留站点实际图床，支持多个懒加载属性，补齐阅读请求头。扩大采样后，《老婆的姊姊》最终话（章节 18635）首张 `484356.jpg` 实际是 HTTP 200、720×307、4227 字节、所有像素为纯白的短空白片；下一张为 720×4200 正文。仅在漫小肆进入章节时检查最多三张开头图片，跳过短、完全空白的图片，首张正文直接进入阅读器共享缓存。逐像素检查保留任何文字或线条，完整高页、黑页和章节中间的图片仍保留。检测失败时保留原图供阅读器重试。
- MangaDex：官方 at-home API 返回章节图片列表，但实网首图为 HTTP 404，原代码只检查列表非空。现在用小范围 GET 验证首图；无图或不可用时回退到镜像中的同作品、同章节。旧收藏中只带章节 UUID 的标识也能恢复作品身份。镜像作品只接受归一化后的完整标题匹配，避免把包含相同角色名的其他作品当成原作。图片请求头由源提供，官方图片不会继承镜像 Referer。
