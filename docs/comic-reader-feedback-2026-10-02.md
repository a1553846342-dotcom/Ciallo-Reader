# 在线漫画翻页、登录与图片加载修复

本轮对应 2026-10-02 的三项需求及附图反馈；保留此前连续搜索、源修复和阅读明细加速改动。

## 已修复

| 反馈 | 修改后的行为 |
| --- | --- |
| 进度条未区分左右阅读 | 横向右到左模式从右端起步；滑块、填充、上一页/下一页箭头及缩略图位置一起反转，页码仍按阅读顺序递增。条漫和无缝滚动保持纵向进度语义。 |
| 预设文字在其他设备消失 | 名称、方向说明和操作按钮分行排列，标签与操作可换行；图标使用完整字符串，避免截断自定义表情。320dp 宽、160% 字号截图已检查。 |
| 老漫画和日漫方向相同 | 日漫默认右到左；老漫画默认左到右。未收到可选问题的答复，按此前说明采用此默认值。升级只更新内置模板，保留自建预设、收藏标记、默认选择以及整本独立配置。 |
| Pica 等没有注册网站入口 | 登录窗口读取源提供的 `account.registerWebsite`，用现有 Z-Library 按钮样式打开浏览器。Pica 的固定地址直接读取，不等待 JS 初始化。动态地址异步读取；源未提供地址时不显示虚构入口。原有站内注册入口继续可用。 |
| 日漫只是反转手势，书脊/卷边仍错误 | 镜像 GL 书本几何、物理页面矩形和触摸坐标，补偿纹理镜像。右到左前进从左侧卷起，书脊在右侧；文字正向，逻辑页码递增。双页模式按两页步进。 |
| 合绘需要临时切换方向 | 仿真双页合成与其他模式按同一阅读顺序排版。日漫拆分半页按右、左阅读，物理显示仍按原画左、右拼接；放大时显示完整跨页。 |
| 其他模式图片策略没有同步 | 仿真、平移、渐变、无动画、磁吸、条漫、无缝滚动共用当前页优先调度。屏幕外图片等待当前页完成，遵守仅 Wi-Fi 预载与并发限制；晋升为当前页后立即加载。翻译后台取图也走相同调度。 |
| 加载错误/内存风险 | 单页、双页、纵向页面共用预览→高清替换与失败重试反馈；高清失败时保留可读预览。解码最多两路、重图像处理最多一路；本地大图更早采样，解码 OOM 清理缓存后低分辨率重试。修正 curl 缓存替换时的字节计量，API 24/25 避免直接引用 HARDWARE 配置。 |

另修复内置预设缺失时 `ensureBuiltinPresets → loadPresets → ensureBuiltinPresets` 的递归问题。

注册地址参考：[Pica 官方源配置](https://github.com/venera-app/venera-configs/blob/main/picacg.js)。应用使用源声明的地址，没有创建账号或提交注册资料。

## 验证结果

- JVM/Robolectric：105 项相关回归通过；另补测 9 项手势回归通过，共 114 个不同用例。大字号页面使用 Roborazzi 记录并检查。
- Android API 35 模拟器：5 项阅读器设备测试全部通过（35.379 秒）。实际 GL Surface 测试覆盖单页/双页 × 左到右/右到左，检查卷起状态、文字朝向和落定页码，保存 12 张截图。
- 七种阅读方式分别使用慢速渐进 JPEG：尾部下载完成前画面已可读，邻页请求数为 0；高清完成后继续预载，当前页均只请求一次。保存 14 张预览/完成截图。
- 当前页晋升测试：邻页等待期间切为可见页能立即加载，随后缓存复用，没有重复请求。无增强模式的渐进预览、高清结果及缓存复用通过。
- 真实《新世纪福音战士》：扑飞与拷贝漫画均搜索成功，第 1 卷各连续解码 20 张图片，共 40 张成功，包含 1500×786 合绘与约 1200×1700 竖页。此处验证的是连续加载和解码；没有复现反馈者未知源、章节、设备及模式下的原始闪退，不能据此认定所有闪退场景已消失。
- 离线 debug、androidTest、release 构建成功；release v2 签名、版本、arm64 ABI、ZIP CRC 与交付副本校验一致。没有运行项目全部 486 项 JVM 测试。
- release 包已在模拟器覆盖安装并成功冷启动（699ms）；随后 Windows 模拟器进程发生 `qemu-system-x86_64-headless.exe / c0000005` 主机崩溃，未获得长期 release 运行结果。该结果不能当成 Android 应用异常，以上阅读器设备回归使用 debug 包。主机事件已记录。
- UI gate 仍有任务开始前已存在的基线超标；本轮字号/圆角/颜色/空描述/sp/contentType 计数增量均为 0，dp 为 −1，未调整基线。

证据：`.workbuddy/reader-feedback-20261002/`。主要日志为 `verified-debug-build.log`、`preset-render-and-gestures.log`、`native-reader-tests-final.log`、`native-strategy-log.txt`、`evangelion-sample.jsonl`。截图位于 `device-images/` 及 `presets-320dp-font160.png`。
