# 漫画资料、收藏换源与长按搜索

本次仅检查并改动漫画源元数据、漫画详情、喜欢入口和设置末尾卡片相关代码。按用户要求，未运行 Gradle、编译或整项目审查。

## 行为

- 各漫画源打开详情时读取真实详情，并保留搜索结果已有的有效资料。JS 源复用 `loadInfo` 的章节请求；作者、简介、别名、画师、标签、状态、语言和更新信息按源站返回展示。副标题不再直接当作者，缺失的作者和简介明确提示缺失。
- JS 桥对普通 Map 保留键和值，章节 Map 仍按原来的目录结构展平。附加的构造器 shim 保留源脚本提供的元数据，Venera 原始 runtime 保持原文件。
- 漫画源管理可查看源 ID、脚本版本、启用状态、搜索、阅读、下载和各自的登录要求。启用和支持能力不表示站点当前联网可用。
- 详情页顶栏 / 封面区域的名字和作者支持长按复制、聚合搜索。搜索会切到书库的聚合漫画搜索，填入关键词并开始搜索。
- 点击喜欢：仅检测到不同来源的相似作品时显示替换 / 并存窗口，没有候选就直接收藏。识别使用繁简、全半角、标点归一化，源站别名、本地 AniList 的唯一精确命中别名，以及标题相似度；相似只作提示，由用户选定替换对象。窗口也允许检索旧收藏。
- 替换使用唯一的标题 / 话号 / 卷号映射；保留小数话号，分话和番外不按普通话号猜测，也不靠章节 ID 或目录位置迁移。新源少话、倒序、缺话或重复话号不会按序号挪动记录。保留原分类；新源已有更强阅读状态或较新页码时保留它。跨来源迁移从对应话第一页续读，未匹配的记录留在旧来源；旧收藏移除，新收藏使用新源资料。批量加入排队处理。
- 设置版本卡片增加 Star 图标和下划线的可爱文案，打开项目仓库 `https://github.com/a1553846342-dotcom/EASYREADER`。
